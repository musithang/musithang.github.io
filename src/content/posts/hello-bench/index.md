This is a place for project logs and technical writing. Mostly Rust, mostly terminals, and whatever obsession is rotating in at the moment: radios, homelabs, containers.

A few ground rules I'd like the blog to keep:

- **Measured over confident.** If a number is estimated, it says so. If a post is old, the page says so too (there is a `[STALE]` banner for exactly that).
- **Small and fast.** Plain HTML you can read without JavaScript. No trackers, no cookie banners.
- **Honest logs.** Devlogs include the dead ends, because the dead ends are where the learning is.

The biggest project right now is [sdrtop](/projects/sdrtop/), a terminal monitor for software-defined radios. Its devlog will land here.
